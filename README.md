# FRDM-RW612 examples

> **Demo，僅供參考，非正式產品。** 這些程式用於示範做法，未經量產等級的驗證，也不提供技術支援或維護承諾。

FRDM-RW612 的 MCUXpresso SDK 26.09.00 範例專案，每個子資料夾是一個獨立專案，SDK 本身沒有修改。

| 專案 | 內容 |
|---|---|
| [frdmrw612_fc1_ssel_test](frdmrw612_fc1_ssel_test/) | Flexcomm1 SPI 的 SSEL0（GPIO6）與 SSEL1（GPIO10）分開控制測試 |

建置步驟見各專案的 README。本 repo 不含 SDK。
